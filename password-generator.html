Password Generator

Create strong, random passwords on your own device. Nothing is sent to a server — the password exists only on this screen until you copy it.

What makes a password strong?

Length beats cleverness. A random 16-character password drawn from letters, digits and symbols has about 104 bits of entropy — far beyond brute-force reach. Every extra character multiplies the combinations an attacker must try.

Rules that actually keep accounts safe

  • Use a different password for every account — reuse is how one leak becomes ten.
  • Store passwords in a password manager, not in notes or chats.
  • Turn on two-factor authentication wherever it is offered — Fayaz's own accounts use it, and it blocks most account takeovers even if a password leaks.
  • Never share a generated password by screenshot; copy it straight into the sign-up form.
Can this site see or store my password?

No. Generation uses your browser's cryptographic random generator (crypto.getRandomValues) and runs entirely on your device. The history list lives only in this tab's memory and disappears when you close the page.

How long should my password be?

At least 14–16 characters for important accounts like email and banking. This generator goes up to 64 for passphrases and API keys.
